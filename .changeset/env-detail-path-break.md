自检页说明里的长路径：折行落在路径分隔符上（不再从中间切断）

`dsh 本体` / `dsh 能不能跑` 那两行的说明是两条长路径拼的（node 的入口 + dsh 的 `bin.js`）。
它是一整串没有空格的字符，浏览器只认空格 / 连字符那类断点，于是折行从路径中间切 ——
实测断成 `…/lib/node_modules/@deepseek-` + `ai/dsh/lib/bin.js`，第二行只剩一小截。

现在按路径分隔符（`/` 与 `\`）切成片段、片段之间插 `<wbr>`，片段本身用
`white-space: nowrap` 包住（只插 `<wbr>` 不够：`@deepseek-ai` 里那个连字符自己就是一个断点，
窄窗口下浏览器会优先断在它上面）。四个宽度实测折行都落在分隔符上、且不横向溢出。

说明文字里有用户机器上的真实路径，所以渲染是**纯文本切分 + 元素**，不走 `v-html`；
`<wbr>` 与 `<span>` 都不引入字符，行里显示的文本与主进程给的原文一字不差。
