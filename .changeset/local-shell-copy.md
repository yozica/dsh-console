本地 Shell（自建终端）也能复制了：有选中时 Ctrl+C 就是复制

用户原话：「自建终端还是不支持复制」。原来只有 dsh 终端打开了 `copyOnSelection` —— 本地 Shell 的
Ctrl+C 被有意留给了中断（它确实要用来停正在跑的命令），于是那一路上一个复制手势都没有，选中文字
之后按什么都没用。

现在两条终端共用同一套手势，分法照 Windows Terminal：

- **有选中** → `Ctrl+C`（非 macOS）或 `Ctrl+Shift+C`（两个平台都认）＝复制，并且**把选中清掉**；
- **没选中** → 原样落回 `\x03` 中断；所以"选中着还想中断"再按一下就是中断。

复制后清选中是必需的：不清的话第二下 Ctrl+C 还是命中复制，"选中着要中断"就永远按不出来。
代码里三步顺序固定为"取文字 → 清选中 → 复制"，反了会复制到空串（自检钉着这个顺序）。
macOS 上 `Ctrl+C` 仍然是中断（那儿复制是 ⌘C，走原生菜单），只额外认 `Ctrl+Shift+C`。

自检相应改了四条：判定体同时判平台 / 选中 / Shift 键位；调用链三步顺序 + 复制完 `return false`；
**两条**终端都打开这个开关（集合相等，将来多一条终端路径会红）；`includeReload` 仍然只有 dsh 终端
（本地 Shell 的 Ctrl+R 是它自己的反向历史搜索）。
