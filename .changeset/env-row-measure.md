环境自检页：圆点与内容不再被拆成两行（`.env-main` 的 flex 基宽改成 0）

窗口一窄，`外部 Node` / `dsh 本体` / `dsh 能不能跑` 那几行的**圆点会一个人留在上一行**、
内容整块掉到下面（窗口越窄掉得越多）。原因：`.env-row` 是 `flex-wrap: wrap` 的一行
（确认区与归属说明那两块要靠它自成一行），而 `.env-main` 的 `flex-basis: auto` 用的是
**内容自己的宽度** —— 说明一长，它就被换行算法挪到下一行。

改成 `flex: 1 1 0`（基宽 0）之后，它永远和圆点并排，宽度也仍然自适应（靠 `flex-grow` 填满）。
真机实测视口 1440 / 1220 / 900 / 760 / 640：改前被挤下去 1 / 3 / 4 / 5 / 7 行，改后全是 0；
「更新 pnpm」按钮也始终留在第一行（试过用 `width: calc(100% - 18px)` 达到同样效果，
但那会把按钮挤到第二行，也把"圆点 + gap"的尺寸抄进了内容规则）。
