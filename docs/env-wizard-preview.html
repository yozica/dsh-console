本页只是设计呈现：它摆的是静态画面，用来评审层次、间距、字号层级、状态色的可读性。真实的交互、动效、滚动、键盘走查与"手感"仍然以应用为准。本页不含任何脚本、不引任何外部资源、不发任何网络请求；两套主题靠同一页里上下两块各自的变量作用域呈现，没有主题切换按钮。

怎么看（请重点盯这几处）
  1. 层次是否拉开：门禁层是五层表面（页底 / 框架 / 面板 / 抬升 / 下沉井）。整屏只有当前步骤卡有阴影 —— 其余元素（后续步骤、提示、提醒行）都不许看起来像"卡片"。看看有没有哪一块"抢"了当前步骤卡。
  2. 浅色下的小字对比度：浅色块的状态词用的是冻结 R-04 加深后的四个取值，压在左轨（最深的表面）与卡片（白色）上都要读得清。请特别看左轨里那几行 11.5px 的状态词。
  3. 间距节奏：标题 → 副标题 6px、副标题 → 卡 20px、块之间 16px、卡内 18 / 20px、左轨 16 / 12 / 12px、底条 10 / 20px。哪一段让你觉得"挤"或"散"，直接说段名。
  4. 文字层级：22px 屏标题 / 15px 步骤标题与结论句 / 13.5px 项名与按钮 / 12.5px 说明 / 11.5px 状态词与元信息 —— 只有这五档，没有第六档。看看有没有两处该分开却同号、或该同号却不同号。
  5. 有没有截断或错位：命令原文、路径、主机名、逃生口按钮文案（较长）在任何宽度下都不该被省略号截断；左轨的节点、脊线与标题应该在同一条竖线上。
  6. 着色纪律：形状是第一信号（实心圆 / 空心环 / 虚线环 / 呼吸），颜色是第二信号；已跳过与测不出来只用墨色，不许借琥珀或玫红。看看有没有哪一处"只靠颜色"在说话。

怎么用它：逐块对照 docs/env-wizard-visual.md 的 §5.1 ~ §5.9 看；任何"这里不对"都请指到具体那一块与那一条间距 / 字号 / 颜色，好让我们决定是改设计还是改实现。凡是规格没讲清的地方，都已用琥珀色「规格待明确」框标在对应那一屏旁边（深色块里），没有替它拍板。
