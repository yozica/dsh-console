1. dsh 终端 + 本地 Shell 合成一个 tab选一个

两者都是「终端 + 一条工具条」，差别只在 dsh 终端是**只读的服务端输出**、本地 Shell 可以有多开。 所以问题其实是：「本地 Shell 那排会话标签」和「dsh 终端」怎么放在一起。

A. 一条统一的会话条（我建议这个） 会话条的第一个条目固定是 dsh 终端（只读），后面是各本地 Shell，「新建本地 Shell」放在最右。 只有一层标签，不会出现「上面一排页面、下面一排会话」两层叠着；本地 Shell 原来的改名 / 关闭照旧。

2. 环境自检挪进设置选一个详情落点

设置里放一张卡，平时只显示**一行结论**（几项正常 / 几项需要注意 / 几项不可用 + 要求的那句 Node 区间）； 「查看详情」才铺开完整那套（每一行的灯、结论、依据、一键修复、安装下载来源、重新检测）。

B. 点「查看详情」→ 就在设置页里铺开 不新增任何表面：卡片下面直接把那 8 行铺出来（与自检页同样的行样式）。最省事，但设置页会变长； 而且自检页原来那个「整页只有这一件事」的观感就没了。
C. 环境自检仍然是一个页面，只是不进左栏 点「查看详情」切到那一页（左栏仍高亮「设置」）。改动比 A 还小，但左栏高亮的位置与页面内容不一致， 看久了容易糊涂。

3. 剩下那七项要不要也动可以多选，也可以全不动

合并 + 挪走之后剩下：控制台 / 终端 / DeepSeek Harness / DeepSeek 用量 / 归档会话 / 插件 / 设置。 你开头说「大多数很少会用到」—— 如果还想再瘦，我列几个说得通的走向（都还没做，等你点）：

候选 怎么动 代价
DeepSeek 用量 并进「控制台」页（做成控制台里的一张卡） 控制台那页会长一些；用量页现在有图表与筛选，得挤一挤
归档会话 并进「设置」页（或并进控制台的一张卡） 归档是列表 + 操作，塞进设置会显得设置页很杂
插件 并进「设置」页 插件页有层栈 / 清单 / 装删升级，是左栏里内容最重的一页之一
DeepSeek Harness 不动（它是主入口，内嵌界面本身） —
控制台 / 终端 / 设置 不动 —
