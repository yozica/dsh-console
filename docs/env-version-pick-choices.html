dsh 版本下拉：三个自绘摆法

2026-10-07 裁定：A 已采纳，并把 C 的时间轴与粘性摘要行合进浮层 —— 用户先选了 A（自绘浮层），随后要求"ac 的能力不能结合吗"，于是落地的是**A 的形态 + C 的画法**：A 的机制 （Teleport 到 body + --z-pop、键盘、点外关闭、ARIA）一个字没动，只把列表换成时间轴， 顶上多一条 sticky 摘要。见 src/renderer/pages/env/EnvUpdateConfirm.vue 与 docs/env-doctor.md §3.6。B 未采用；这份预览按仓库惯例保留，作为摆法记录。
2026-10-07 后续裁定：这个版本下拉只有 dsh 那一档有 —— pnpm 不做选版本。 用户问过"为什么 pnpm 不支持跨版本切换"，听完理由（pnpm 的 store 布局按大版本走，跨大版本要连同 profile 的依赖一起迁移，那是一次单独的迁移动作）之后决定 pnpm 固定在线内最新。下面这些摆法仍然 适用于 dsh 那一档。

目的是替掉现在的原生 <select>（它的弹出列表由操作系统画，样式插不进去， 所以那一片和整个界面都不搭）。三个候选都用你们现有的令牌与控件语汇： --surface-2 / --hairline-strong / --r-panel / --shadow-focus，版本号一律 --mono。

A · 自绘浮层 （最接近原生行为）

点触发器弹一层，宽同卡片、限高 232px 内部滚动。
＋ 不挤动卡片；键盘 ↑↓ / Enter / Esc 与点外关闭。
− 仍然是浮层，卡片窄时会被裁（要 Teleport 或调层号）。

B · 卡片内联展开 （不开浮层）

列表直接长在卡片里，把下面的内容顶下去。
＋ 没有裁剪与层号问题；滚动条就是页面自己的。
− 30 个版本会把卡片撑得很高，"将要执行"被顶出视野。

C · 版本时间轴 （推荐）

把发行列表画成一条轴：节点串起来，当前是实心绿点、目标是 accent 环； 从当前往目标走的那一段轴变色，并在旁边挂一个 ↓ 降级。
＋ 一眼看出"我在哪、要去哪、是升是降"——原生 select 永远给不了这个。
