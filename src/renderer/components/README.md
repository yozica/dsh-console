# `components/` —— 通用组件（今天为空）

放这里的**唯一判据**：这个 `.vue` 被**两处以上**真的 import（两个页面 / 外壳 + 页面 / 两个特性）。

- **只有一处用的，跟着那一处走**：页面与页面私有的子件放 `pages/<一处>/`，门禁层（覆盖层）的子件
  放 `gate/`，应用外壳（左栏 / 顶栏 / 状态栏 / 关闭确认）放 `layout/`。
  这条与 AGENTS §7.33 的样式分层判据同源（"只有这一页在用就跟着组件走"），也满足 §7.8 的
  "每个组件都必须有人用"。
- **纯逻辑不在这里**：`utils/`（纯工具）/ `state/`（跨页共享状态）/ `shared/`（跨特性共用的逻辑），
  哪一层都不许有 DOM（见 §7.36 与 §7.37）。
- **今天一个组件都没有**：28 个 `.vue` 里 14 个是"只被挂载"的单品、14 个只有一个父级。
  `GateOutput.vue` 一度看着像共享件（`PluginOpPanel.vue` 的注释里点了它的名），但它其实只被
  `gate/EnvGate.vue` import —— 两边只是"同一套做法"，不是同一个组件。真要出现第二个消费者时，
  把那个组件挪进来，并在 AGENTS §2 的目录树里补一行。
